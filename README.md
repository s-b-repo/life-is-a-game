# life-is-a-game

An unfinished 3D hobby FPS built on top of the Dani "stupid rigidbody
movement" tutorial, with some spawn helpers and terrain assets.

> **Status: broken / partial Unity dump.** Will not currently open in
> Unity as-is. See "Known issues" below.

## What's actually here

- `assets/PlayerMovement.cs` — Dani-style rigidbody FPS movement (the
  comment `// Some stupid rigidbody based movement by Dani` is in
  there verbatim).
- `assets/MoveCamera.cs` — camera follow.
- `assets/random spawn.cs`, `assets/SPAWNRANDOM.cs` — two spawn
  scripts, near-identical duplicates of each other.
- `assets/the world is a game.unity` — the intended main scene.
- Terrain data, prefabs, imported store assets, ~30 image files.
- 29 `.csproj` and 2 `.sln` files (auto-generated by Visual Studio;
  should not be in git).

## Known issues

- **`assets/` is lowercase.** Unity requires `Assets/` with a capital
  A; on case-sensitive filesystems (most Linux, macOS with case-
  sensitive volumes) Unity refuses to load the project.
- **No `ProjectSettings/`** and **no `Packages/manifest.json`**.
  Unity uses `ProjectSettings/ProjectVersion.txt` to know which
  editor version to invoke; without it the editor can't open the
  project cleanly.
- **~30 orphaned `.meta` files** — `.meta` files that reference
  folders which were never committed (e.g. `Aura.meta`,
  `Photon.meta`). Unity will log warnings.
- **`Rigidbody.velocity` deprecation** — Unity 6 renames this to
  `linearVelocity`. Movement scripts here still use the old name.
- **Old Input Manager** — uses `Input.GetKey(...)`. Fine for legacy,
  needs a port for the new Input System.
